# Module 2 Interview Practice

For every topic, answer in this order: definition, invariant, request flow, failure mode, trade-off, telemetry, and a production example. Practice aloud with a 2-minute answer, then extend it for a senior follow-up.

## High-value prompts

- Design a retry-safe create-order API.
- Compare session authentication and JWTs.
- Explain refresh-token rotation and replay detection.
- Diagnose rising p99 latency in a FastAPI service.
- Decide when work belongs in a queue.
- Explain service/repository boundaries without over-engineering.
