# Module 2: Core Backend Revision Map

Use this module as a night-before-interview map. Read HTTP and API contracts first, then authentication, architecture, asynchronous work, and observability. Every numbered chapter includes a two-minute section, mistakes, questions, cheat sheet, and related links.

## Suggested order

1. HTTP, REST, status codes, API design.
2. Sessions, JWT, refresh tokens, password hashing, authentication flow.
3. MVC, service/repository patterns, clean architecture, dependency injection.
4. Workers, cron, async processing.
5. Logging, errors, monitoring, observability, SOLID, clean code.
