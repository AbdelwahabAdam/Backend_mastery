# Module 2 Practice Tasks

## API contract
Build a FastAPI order endpoint with validation, stable errors, idempotency keys, PostgreSQL constraints, and structured logs.

## Authentication
Add Argon2id passwords, sessions or JWT access tokens, refresh-token rotation, logout, and security-event auditing.

## Async reliability
Implement a PostgreSQL outbox plus Redis/queue worker. Test duplicate delivery, timeout, restart, and dead-letter handling.

## Operations
Add metrics, traces, dashboards, alert/runbook, Docker configuration, graceful shutdown, and a load/failure test report.
