# Interview Questions

Practice answers aloud. Every answer should define the invariant, state assumptions, compare alternatives, and explain how you would prove or observe the design.

## Junior

### 1. Explain the core invariant and a simple implementation.
**Question**  
Apply the answer to **04 Process vs Thread**.

**Expected Answer**  
Define terms correctly, walk a small example, and name a boundary case. Tie the reasoning to **04 Process vs Thread** and distinguish local implementation behavior from distributed production behavior.

**Follow-up Questions**  
- Which metric, trace, profile, or test would validate your claim?
- What input, deployment, or failure case breaks the default assumption?
- What is the smallest safe rollback?

**Common Mistakes**  
Repeating a definition without an invariant; claiming complexity without constraints; ignoring limits, retries, concurrency, or observability.

**Difficulty**  
Foundational

**Why Interviewers Ask It**  
This reveals whether the candidate can turn theory into safe production reasoning.
